# Telugu Context AI

A Telugu language processing application that combines transliteration, translation, tone detection, and conversational context analysis to better understand Telugu messages written in either Romanized Telugu or Telugu script.

## Features

- **Telugu Transliteration** – Converts Romanized Telugu input into Telugu script using IndicXlit.
- **Telugu to English Translation** – Translates Telugu text into English using IndicTrans2.
- **Tone Detection** – Identifies the tone of a message using MuRIL and Gemini AI.
- **Context-Aware Tone Analysis** – Uses conversational context to improve tone interpretation when previous messages are available.
- **Context Classification** – Analyzes the relationship between a current message and the preceding conversation.
- **Hybrid AI Pipeline** – Combines locally running NLP models with Gemini API-based inference.

## Architecture

The application follows a sequential NLP pipeline:

1. Accepts text in Romanized Telugu or Telugu script.
2. Converts Romanized Telugu into Telugu script using IndicXlit.
3. Translates the Telugu text into English using IndicTrans2.
4. Analyzes the tone of the message.
5. If conversational context is provided, performs context classification and context-aware tone analysis.

### Tone Analysis

- Without previous conversation, the application uses the MuRIL tone classification model.
- If MuRIL predicts a neutral/no-tone result, Gemini is used as a fallback.
- When previous conversation is provided, Gemini is used directly for tone analysis with contextual information.

## Installation

### 1. Clone the repository

```bash
git clone https://github.com/RahulCoding-R/Telugu_context_nlp.git
cd Telugu_context_nlp
```

### 2. Create a virtual environment

```bash
python -m venv .venv
.venv\Scripts\activate
```

### 3. Install dependencies

Install the main application dependencies:

```bash
pip install -r requirements.txt
```

Install the transliteration service dependencies separately:

```bash
pip install -r requirements-xlit.txt
```

### 4. Configure the API key

Create a `.env` file in the project root and add:

```env
GEMINI_API_KEY=your_api_key_here
```

Replace `your_api_key_here` with your own Gemini API key.

### 5. Download and configure the models

Download the required pretrained model files and place them in their corresponding directories inside `models/`.

The model directories are expected to be available locally before running the application.

## Running the Application

Start the application using:

```bash
start_app.bat
```

The application starts the backend services required for transliteration and NLP processing.

Once the backend is running, open the application in your browser at:

```text
http://127.0.0.1:8000
```

## API

### `POST /api/process`

Processes Telugu text through the NLP pipeline.

**Input:**

```json
{
  "text": "Nuvvu chala manchivadivi",
  "previous_conversation": ""
}
```

**Processing includes:**

- Transliteration into Telugu script
- Telugu-to-English translation
- Tone analysis
- Context classification when previous conversation is provided

## Limitations

- NLP accuracy may vary depending on spelling, slang, dialect, and sentence structure.
- Romanized Telugu has no standardized spelling, which can affect transliteration.
- Tone detection is probabilistic and may not always capture sarcasm, intent, or subtle conversational meaning.
- Contextual interpretation depends on the quality and availability of previous conversation.
- Local pretrained models require additional storage and are not bundled with the repository.

## Disclaimer

This project is developed for educational and experimental purposes. The interpretations generated by the models should not be considered definitive representations of a person's intent or emotions.
